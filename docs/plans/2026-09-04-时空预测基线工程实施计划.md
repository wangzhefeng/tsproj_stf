# 时空预测基线工程 M0～M5 实施计划

> **For Hermes:** Use test-driven-development and executing-plans skills to implement this plan task-by-task. Do not commit until wangzf reviews the complete changeset.

**Goal:** 将 `tsproj_stf` 建成具有项目自有数据/评估契约、BasicTS 训练后端、STID 与 Graph WaveNet 基线、电力数据适配和分位数预测能力的可复现实验工程。

**Architecture:** 项目内部使用 `[time, node, feature]` 标准数据结构，所有科学协议由 `tsproj_stf` 校验并留痕；BasicTS 1.1.0 只承担训练循环和 STID 后端。Graph WaveNet、确定性基线、指标、数据适配及实验产物由项目维护。

**Tech Stack:** Python 3.10.11、uv、NumPy、Pandas、PyTorch、BasicTS 1.1.0、PyYAML、pytest。

**Execution policy:** 严格按 M0→M1→M2→M3→M4→M5 顺序执行；每个代码任务走 RED→GREEN；阶段门禁失败时停止推进并修根因。正式长训练与私有电力数据均不得用伪造结果代替。
